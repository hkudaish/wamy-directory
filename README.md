# دليل الموظفين والتحويلات

تطبيق ويب عربي RTL يعمل محليًا من المتصفح، ويشمل:
- هوية الندوة العالمية للشباب الإسلامي وشعارها وألوانها المؤسسية في واجهات التطبيق.
- بحث فوري بالاسم والمنصب والإدارة والقسم والتحويلة.
- تصنيفات وظيفية وفلاتر سريعة.
- مفضلة محفوظة في المتصفح.
- عرض الهيكل الإداري إما كشجرة إدارات وأقسام أو كبطاقات للتصنيفات الوظيفية.
- عرض مكاتب الندوة الدولية كبطاقات قابلة للطي مرتبة حسب التسلسل الوظيفي.
- حقول المكتب والدولة والجوال والبريد الإلكتروني لجميع الأفراد مع روابط اتصال مباشرة.
- شارة دائمة لآخر تحديث فعلي لبيانات الدليل.
- وضع مستخدم / مسؤول لإدارة البيانات.
- إضافة تصنيفات الدليل وتعديل أسمائها وحذف التصنيفات غير المستخدمة من وضع المسؤول.
- إضافة وتعديل وحذف السجلات.
- استيراد وتصدير CSV.
- تصدير واستيراد نسخة احتياطية كاملة بصيغة JSON تشمل البيانات والتصنيفات والمفضلة والسجلات وحسابات المستخدمين والإعدادات.
- سجل تغييرات محلي.
- منشئ طباعة / PDF يدعم A3 وA4 وA5 واتجاه أفقي أو عمودي.
- قوالب جاهزة: القيادات، مديرو الإدارات ونوابهم ومديرو المكاتب، رؤساء الأقسام، الدليل الكامل، المفضلة.

## التشغيل
افتح ملف `index.html` مباشرة في Chrome أو Edge. لا يحتاج إلى خادم.

## حفظ PDF
من شاشة "الطباعة والتصدير" اختر حجم الورق والفئات، ثم "معاينة وطباعة PDF"، وبعد فتح نافذة الطباعة اختر "حفظ كملف PDF".

## البيانات
يحتوي التطبيق على 323 سجلًا وظيفيًا: 159 سجلًا للمقر واللجان، إضافة إلى 164 منسوبًا موزعين على 33 مكتبًا دوليًا، وقد حُدّثت بيانات المكاتب من ملف الهيكل الإداري المرفق. تشمل البيانات الإدارة والقسم والمكتب والدولة والرقم الوظيفي والجوال والبريد الإلكتروني بحسب المتوفر في المصدر. يمكن تحديث السجلات من وضع المسؤول أو عبر ملف CSV.
